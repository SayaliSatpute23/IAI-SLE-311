## Review Process

AI-generated code is not accepted without checking it.

For each AI-assisted contribution, the student will:

1. Review the generated code.
2. Understand what the code does.
3. Check the code for errors.
4. Modify the code where required.
5. Run and test the program.
6. Record significant AI-generated contributions in this log.

## Student Responsibility

The student is responsible for understanding, reviewing, testing, and
maintaining the final project code.
